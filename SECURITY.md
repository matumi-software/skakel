# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately through GitHub: on the
repository's **Security** tab, choose **Report a vulnerability**. Only the maintainers see the report.

Include what you found, the version or commit, and the steps to reproduce it. Skakel is maintained
by one person in their own time, so expect a reply within 30 days. Once a fix ships, the advisory is published and you are credited unless you would
rather not be.

## Supported versions

Only the latest release gets security fixes.
